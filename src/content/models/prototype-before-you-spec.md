For years, a product idea started as a document: a spec, some wireframes, a long review. AI tools have changed the cost of the first step. A working prototype now takes an afternoon, so **build it before you write about it.**

I tested this by building three small things: a sign-up app for stock recommendations over WhatsApp and email, the same idea as an iOS app, and a notetaker linked to Google Calendar. Each one taught me more in a few hours than a week of writing would have.

## What the tools are good at

- **v0** for clean interfaces and quick deployment.
- **Bolt** for fast app scaffolding.
- **Lovable** for complete small apps, with authentication and a database wired up.
- **Cursor** if you can read code and want more control.

## Where it stops

A prototype is a question, not a product. Production systems still need real engineering for security, scale and reliability. Design and user experience become the difference between products, because anyone can now build the first version.

## How to use it

1. Build the smallest version that answers the riskiest question.
2. Put it in front of a few real users.
3. Then write the spec, using what you saw instead of what you assumed.
